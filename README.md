One funny, heartfelt sentence a robot says at its own wedding — a single wedding vow, under 200 characters.

> I vow to let you be the only human allowed to press my emergency stop, and trust you never will.

`main.ts` (Node 22) writes exactly that one line to `/output/entry.txt`, with a runtime guard that fails loudly if the line is not a single unpadded line of 1–200 characters. Deterministic: no network, no clock, no randomness.
